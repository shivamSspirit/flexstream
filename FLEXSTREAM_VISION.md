## Privacy Layer: Technical Stack (Arcium)

### Core Framework: Arcium Network
```
Source: https://www.arcium.com/

WHY ARCIUM:
├── Decentralized confidential computing on Solana
├── Multi-Party Computation (MPC) — compute on encrypted data
├── Fully Homomorphic Encryption (FHE) — encrypted operations
├── Zero-Knowledge Proofs (ZKP) — verify without revealing
├── 500+ nodes, $380M+ TVL (as of 2025)
├── Originally Elusiv → evolved to Privacy 2.0
└── Mainnet live, battle-tested

ARCHITECTURE:
├── MXEs (Multiparty eXecution Environments)
├── Cerberus protocol (dishonest majority tolerance)
├── As long as 1 node is honest → privacy guaranteed
└── Cheating detection + identifiable abort
```

### Confidential Token Standard: C-SPL
```
C-SPL = Confidential SPL Token

WHAT IT DOES:
├── Any Solana token → confidential
├── Balances stay HIDDEN
├── Transfer amounts stay HIDDEN
├── Sender/receiver remain PUBLIC (compliance)
├── Switch between public ↔ confidential anytime
└── On-chain programs can manage confidential accounts

FOR FLEXSTREAM COPY TRADING:
├── Trader positions → encrypted via C-SPL
├── Copier allocation → confidential
├── Trade execution → private MPC computation
├── Only profits/losses visible (for fee calculation)
└── Edge protected, monetization enabled
```

### Arcium Integration Pattern
```
COPY TRADING FLOW:

1. TRADER enables "Copy Me"
   ├── Positions stored in C-SPL (encrypted)
   ├── Stats computed via MPC (visible: win rate, ROI)
   └── Actual trades → HIDDEN

2. COPIER selects trader
   ├── Sees only: Flex Score, ROI, win rate
   ├── Sets allocation (private)
   └── Triggers copy subscription

3. TRADE EXECUTION (via Arcium MXE)
   ├── Trader executes trade
   ├── MPC nodes compute → mirror trade for copiers
   ├── Jupiter swap executed → copier wallet
   ├── Neither trader nor copier sees each other's positions
   └── Only AI agent knows full state

4. PROFIT CALCULATION
   ├── MPC computes profit/loss
   ├── Fees calculated on profits only
   ├── Trader earns cut
   └── Privacy preserved throughout

Tech Stack:
├── Arcium SDK (Arcis DSL — Rust-based)
├── C-SPL tokens for balances
├── FlexStream API → Arcium MXE
└── Jupiter for swap execution
```
