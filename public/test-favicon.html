🔧 Not seeing the new favicon? Try this:

  1. Hard Refresh:
    • Chrome/Edge: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
    • Firefox: Ctrl+Shift+R or Cmd+Shift+R
    • Safari: Cmd+Option+R
  2. Clear Browser Cache:
    • Chrome: Settings → Privacy → Clear browsing data → Cached images
    • Firefox: Settings → Privacy → Clear Data → Cached Web Content
    • Safari: Develop → Empty Caches
  3. Close & Reopen: Close ALL browser tabs for this site, then reopen
  4. Incognito/Private: Open in incognito/private mode to see it fresh
💡 Pro Tip: If you're running a dev server, restart it and visit http://localhost:3000/?v=2 to bust the cache!
