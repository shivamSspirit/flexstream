## 🎨 Using Backgrounds in PowerPoint/Keynote

### **PowerPoint (Recommended: PNG):**
1. Right-click slide → "Format Background"
2. Select "Picture or texture fill"
3. Click "File..." → Choose `deck-bg-hero.png` (or `-4k.png` for high-res)
4. Set transparency to 0%
5. Apply to all slides or one at a time

**Pro Tip:** PNG files work better in PowerPoint than SVG. Use standard PNG for most presentations, 4K PNG if presenting on high-resolution displays.

### **Keynote (Works with both SVG and PNG):**
1. Click "Format" → "Background"
2. Choose "Image Fill"
3. Click "Choose..." → Select `deck-bg-hero.png` (or `.svg`)
4. Set "Fill" to "Scale to Fill"

**Pro Tip:** Keynote handles SVG well, but PNG is safer for consistent rendering.

### **Google Slides (Both formats work):**
1. Right-click slide → "Change background"
2. Click "Choose image"
3. Upload `deck-bg-hero.png` or `deck-bg-hero.svg`
4. Click "Done"

**Pro Tip:** For faster uploads, use PNG. For better quality at any zoom level, use SVG.

## 💡 Pro Presentation Tips

### **Visual Hierarchy:**
1. **Use big, bold headlines** (48-72pt font)
2. **Limit text** (max 3 bullets per slide)
3. **Add visuals** (mockups, screenshots, icons)
4. **Show, don't tell** (use images over words)

### **Storytelling Arc:**
```
Problem (pain) → Solution (relief) → Opportunity (excitement) → Close (urgency)
```

### **Timing:**
- **Title:** 10 seconds
- **Problem:** 45 seconds
- **Solution:** 60 seconds
- **How It Works:** 45 seconds
- **Market:** 30 seconds
- **Traction:** 45 seconds
- **Model:** 30 seconds
- **Competition:** 30 seconds
- **Team:** 30 seconds
- **Close:** 30 seconds

**Total:** ~6 minutes (leaves 1-2 min for Q&A)

## 🎭 Slide Animation Recommendations

### **Keep it minimal!**
- **Entrance:** Fade In (0.3s)
- **Exit:** None (don't exit, just advance)
- **Emphasis:** Pulse (for key numbers only)

**Avoid:**
- ❌ Swivel, bounce, fly-in effects (looks amateur)
- ❌ Sound effects (distracting)
- ❌ Excessive animations (judges hate this)

## 🚀 Colosseum-Specific Tips

### **For Stage Projection:**
1. **Test colors on projector** (they may look different)
2. **Increase font sizes** (stage = farther away)
3. **High contrast text** (F5F5F7 on dark bg)
4. **Avoid small details** (won't be visible from back)

### **For Judges:**
1. **Lead with problem** (they need to feel pain)
2. **Show traction early** (if you have it)
3. **Emphasize Solana-native** (you're in Solana ecosystem)
4. **Clear differentiation** (why not Twitter/Pump/Telegram?)

### **For Audience:**
1. **Memorable tagline** ("Your Vibe = Your Income")
2. **Viral messaging** ("Don't Sleep On This")
3. **FOMO element** ("100 beta spots only")
4. **Clear CTA** (QR code to waitlist)
