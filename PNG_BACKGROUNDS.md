## 🚀 Quick Start Guide

### **For PowerPoint Users:**
1. Open PowerPoint
2. Right-click on slide → "Format Background"
3. Select "Picture or texture fill"
4. Click "File..." → Browse to `~/Desktop/`
5. Choose `deck-bg-hero.png` (or any other background)
6. Click "Apply to All" or just current slide

**Best Practice:** Use standard HD PNG files unless presenting on 4K displays.

---

### **For Keynote Users:**
1. Open Keynote
2. Click "Format" inspector → "Background"
3. Choose "Image Fill"
4. Click "Choose..." → Select PNG from Desktop
5. Set "Fill" to "Scale to Fill"

**Best Practice:** Keynote works great with both SVG and PNG, but PNG is more predictable.

---

### **For Google Slides Users:**
1. Open Google Slides
2. Right-click slide → "Change background"
3. Click "Choose image"
4. Upload PNG file from Desktop
5. Click "Done"

**Best Practice:** PNG files upload faster than SVG and render consistently.

## 🎨 File Specifications

### **Standard HD PNG (1920×1080)**
- **Resolution:** 1920×1080 pixels (Full HD)
- **DPI:** 300 (print quality)
- **Color Space:** RGB
- **Compression:** PNG-9 (maximum quality)
- **Background Color:** #0A0A0F (midnight blue-black)

### **4K PNG (3840×2160)**
- **Resolution:** 3840×2160 pixels (Ultra HD)
- **DPI:** 600 (ultra high quality)
- **Color Space:** RGB
- **Compression:** PNG-9 (maximum quality)
- **Background Color:** #0A0A0F (midnight blue-black)

## 💡 Pro Tips

### **File Management:**
- Keep both resolutions on your Desktop for quick access
- The original SVG files are also available if you need vector scaling
- All files use FlexIt's professional color palette (Solana purple #9945FF, Phantom cyan #14F195)

### **Presentation Software:**
- **PowerPoint:** Always use PNG (best compatibility)
- **Keynote:** PNG or SVG both work (PNG is safer)
- **Google Slides:** PNG recommended (faster upload, consistent rendering)
- **Canva/Figma:** Use SVG files instead (infinite scaling)

### **Quality:**
- Standard HD is perfect for 95% of presentations
- Only use 4K if you know you have a high-res display
- Larger files don't always mean better on standard projectors

## 🔄 Converting More Backgrounds

If you need to convert additional SVG files to PNG, run:

```bash
# Standard HD (1920×1080)
node convert-deck-backgrounds.js

# 4K Ultra HD (3840×2160)
node convert-deck-backgrounds-4k.js
```

Both scripts are in your project folder and will save PNG files to your Desktop.
