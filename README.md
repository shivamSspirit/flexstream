# FlexIt - Social Platform for Solana

A modern social media platform built for crypto traders and streamers to showcase their success, share stream highlights, and connect with the community.

FlexIt is a Solana-native social dApp that enables creators to mint free, tradable tokens from every post using Meteora DBC backend integration. It solves fragmented monetization by integrating a verified creator reputation system linked to wallets and Twitter, dual-token economics for profile and post-level assets, and private token-gated copy trading to protect strategies.


Key features:

Instant, no-cost token minting for posts  
On-chain verified reputation and achievement badges  
Automated liquidity via meteora pools  
Secure, token-gated copy trading with verified performance  
Multiple monetization channels: subscriptions, tipping, and trading fees

Currently in beta on Solana DevNet, FlexIt combines social, DeFi, and privacy layers to build scalable, transparent creator economies.
